# План разработки Telegram Mini App для тренера

## 6 пунктов плана работ

1. **Data Foundation & Backend API** — проектируем БД (клиенты, программы, тренировки, RIR, e1RM) и REST API с permission layer; даёт надёжное хранение данных и основу для всех функций приложения.

2. **Telegram Auth & Mobile UI Core** — реализуем авторизацию через Telegram и адаптивный мобильный интерфейс (карточки упражнений, offline-first, sync queue); даёт быстрый UX на iPhone/Safari и работу без интернета.

3. **Analytics Engine & Audit Trail** — создаём движок расчёта KPI (графики e1RM, объём, прогрессия, deload signals) и систему аудита всех изменений; даёт тренеру объективную аналитику и историю решений.

4. **AI Orchestrator & Tool Layer** — разрабатываем главного координатора агентов с системой инструментов и структурированными ответами (confidence, proposal format); даёт контролируемое взаимодействие AI с данными без прямого доступа к БД.

5. **Specialized AI Agents (Training + Nutrition)** — реализуем агентов анализа тренировок (RIR, e1RM, прогрессия) и питания (качество данных, 7/14/28-дневные тренды, КБЖУ коррекции); даёт предметные рекомендации по ключевым доменам.

6. **Safety Agent & Human Approval Flow** — создаём агента проверки ограничений/конфликтов и интерфейс подтверждения рекомендаций тренером перед выполнением; даёт защиту от рискованных изменений и сохраняет контроль за человеком.
